# Story Time

Gentle bedtime stories for little ones. Pick a hero, a place, and a lesson, and the app writes a short, soothing story that always ends with a yawn, a snuggle, and goodnight.

- All characters are original. No photos, no faces of real people.
- Stories come from an on-device template engine (seeded, so a story code always rebuilds the same story). No AI services, no network calls for content.
- Read-aloud uses the device's built-in speech voices.
- Favorites are stored only on this device (IndexedDB). No accounts, no analytics.

Vendored: Nunito font (SIL Open Font License 1.1).
